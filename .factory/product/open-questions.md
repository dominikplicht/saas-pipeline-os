# Open Questions — SaaS Pipeline OS

## Product

1. Should v0 be fully static/template-driven first, or include AI generation immediately?
   - Current recommendation: static/template-driven first to validate the workflow and avoid model-integration distraction.

2. Should the first target user remain Dominik only, or include other solo builders from the beginning?
   - Current recommendation: Dominik-first, but with generic language that can later support solo founders.

3. Should outputs be optimized for Notion, GitHub, or plain Markdown?
   - Current recommendation: plain Markdown first, with sections that map cleanly to Notion and Development Factory files.

4. Should this become a standalone SaaS or remain an internal Lucian/Development Factory module?
   - Current recommendation: internal product first. External SaaS only after repeated proof of pain.
