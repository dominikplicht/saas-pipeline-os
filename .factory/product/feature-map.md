# Feature Map — SaaS Pipeline OS v0.1

## Core workflow

```text
Idea Intake
→ Segment Candidates
→ Pain Statements
→ Pain Score
→ Fake-Pain Check
→ Interview Plan
→ MVP Scope
→ Pre-Factory Validation Pack
→ Development Factory Handoff
```

## Feature slices

### Slice 1 — App shell and positioning
- Homepage/dashboard
- Product title
- Pipeline explanation
- MVP scope guard

### Slice 2 — Idea intake
- Raw idea textarea
- Source field
- Context field
- Submit/generate button placeholder

### Slice 3 — Target segment module
- Segment candidate cards
- Segment score dimensions
- Primary segment selection placeholder

### Slice 4 — Pain scoring module
- Pain statement cards
- Score breakdown
- Primary pain recommendation
- Fake-pain warning

### Slice 5 — Interview plan module
- DM template
- Pain interview questions
- Evidence record template

### Slice 6 — Factory handoff module
- Pre-Factory Validation Pack output
- Copy-to-clipboard button
- Development Factory mapping

## Deferred features

- Authentication
- Database persistence
- AI API integration
- Notion integration
- GitHub integration
- Vercel deployment management
- CRM/outreach automation
