# Factory Examples

This directory contains non-executable examples for the Development Factory Blueprint.

Examples in this folder are documentation only. They must not be treated as active product-instance state by planners, workers, CI scripts, or automation.

## Rules

- Examples must stay under `docs/factory/examples/`.
- Examples must be clearly labeled as examples.
- Examples must not appear under `.factory/tasks/ready/`.
- Examples must not appear under `.factory/runs/`.
- Examples must not be referenced as active tasks in `.factory/tasks/task-graph.yaml`.

## Available examples

- `ready-task.example.yaml` — example structure for a scoped ready task.
