# ChatGPT Product Pipeline Prompt

/goal
Process this SaaS idea through the SaaS Pipeline OS validation workflow:

[PASTE IDEA / LINK / SCREENSHOT SUMMARY]

Work in this order:

1. Create an Opportunity Brief.
2. Identify 3–5 target segment candidates.
3. Generate concrete pain statements for each segment.
4. Score each pain by:
   - frequency
   - intensity
   - willingness to pay
   - reachability
   - MVP feasibility
   - differentiation
5. Flag fake-pain risks.
6. Recommend one primary target segment and one primary pain.
7. Create a 5–10 user outreach and interview plan.
8. Define the smallest MVP slice.
9. Produce a Pre-Factory Validation Pack.
10. Map the output to:
   - product-intent.md
   - prd.md
   - roadmap.md
   - feature-map.md
   - task-graph.yaml

Constraints:
- Do not jump to features before the pain is clear.
- Treat polite interest as weak evidence.
- Treat workarounds, complaints, repeated use, and willingness to test/pay as stronger evidence.
- Keep the MVP small enough for a Development Factory first preview.
